# 梦潮官网交接（2026-11-06）

## 当前状态

- 本地网站已实现首页 4 个横向章节和应用介绍 10 个横向页面。滚轮向下前进、向上返回；手机可左右滑动。页面本身不连续向下滚动。
- 首页展示「刻梦、梦的层次、循迹、带走一场梦」。点击截图展开同一章节内的图片和文字说明。
- 应用介绍展示首页、下载、功能总览、6 个功能页和结尾下载页。功能页的静态截图可展开图文说明；视频保留播放控件。
- 页面使用 `LivingFoam` Canvas 光点泡群，按章节切换颜色和分布，并响应指针；首页另有水面扰动效果。用户已接受当前光点方向，最终美术效果仍以人工目视验收为准。
- 下载区从本仓库公开 GitHub Release 读取 APK 信息。不要在前端加入私有仓库凭据。

## 本地启动与复查

```bash

corepack pnpm test:run
corepack pnpm build
```

本地页面通常位于 `http://127.0.0.1:5175/dreamtide-website/`；端口以 Vite 实际输出为准。重点人工路径：横向翻完首页 4 章；点击每章截图并返回；进入应用介绍，逐页翻到结尾；展开静态截图图文页；检查 320px 手机、768px 平板和 1440px 桌面布局。
