# 梦潮官网媒体替换设计

## 目标

使用 `public/media/` 中现有的 9 个正式图片和视频替换或扩充页面媒体，确保每个新增素材至少展示一次。尚无对应素材的媒体槽继续显示固定比例占位，不使用无关内容填充。

## 格式策略

- 图片保留现有 JPG 或 PNG，不进行无收益的重复转码。
- 操作演示保留 MP4，不转换为 GIF。MP4 通常体积更小、画质更好，也更适合移动浏览器播放。
- `MediaFrame` 根据文件扩展名选择 `<img>` 或 `<video>`。
- 视频静音、循环、行内播放。非首屏视频延迟加载，避免页面打开时同时请求全部资源。
- 启用 `prefers-reduced-motion: reduce` 时不自动播放视频。
- 视频加载失败时沿用现有固定比例占位。

## 素材映射

全部素材按以下关系展示：

- Hero 首页：`首页.mp4`
- 功能「记录与保存」：保留占位，等待正确的记录演示
- 功能「标签、注记与隐私设置」：`编辑-隐.jpg`
- 功能「隐私浏览」：`不谈人间事.mp4`、`春梦了无痕.mp4`
- 功能「档案与词云回看」：`档案.jpg`
- 教程「写下第一场梦」：保留占位，等待正确的记录演示
- 教程「保存、整理与分享」：`分享.png`
- 教程「回到梦潮回看」按操作顺序展示一组媒体：
  1. `档案 筛选.jpg`
  2. `档案 正文.mp4`
  3. `词云.mp4`
- 教程「下载并安装」：保留占位

档案相关的三份素材共同构成筛选、阅读正文、从词云重新进入记录的回看流程。该教程步骤允许多个媒体连续展示，其余步骤仍保持单一媒体。

## 功能说明

功能区不再只写一句简介。每项按“入口、操作、结果”说明：

- 记录与保存：从首页进入刻梦，填写正文后暂存草稿或正式保存。
- 整理：保存后添加情绪、场景、内容、分类、人物等标签，并可添加全文或片段注记。
- 隐私标记：点“隐”，先选模式，再划选正文并在弹窗确认。
- 不谈人间事：浏览时在“显、隐、化”间切换，以水墨遮盖人物原名，并可显示化名。
- 春梦了无痕：浏览时在“显、隐”间切换，以删除动画隐藏私密片段，以打字动画恢复。
- 档案回看：进入档案后按关键词、标签、人物、分类或日期筛选，再打开正文。
- 词云回看：从首页词云选择词语，进入包含该词的相关梦境。
- 分享：从档案阅读页生成纵向长图，预览后保存或调用 Android 系统面板分享；图片遵守当前隐私显示状态。
- 本地备份：从设置导出 JSON 并自行保管；当前没有云同步和备份恢复。

## 组件与内容调整

- 扩展 `MediaFrameProps`，保持现有调用方式兼容，并支持视频渲染。
- 教程媒体数据支持一项或多项，`Tutorial` 统一按数组渲染；单项时保持现有布局，多项时使用响应式媒体序列。
- 视频和图片均使用 Vite `BASE_URL` 构造 GitHub Pages 子路径。
- 更新占位文案，使其涵盖截图和视频。
- 在 `siteContent.ts` 与 `Hero.tsx` 中替换全部媒体路径及准确替代文本。
- 教程第三步文案调整为「保存、整理与分享」，与分享图内容一致。
- 更新 `public/media/README.md`，记录实际格式、路径和后续替换规则。
- 不覆盖当前工作区中用户已有的 README、Hero 文案和测试修改；只对实现媒体支持所需位置做最小改动。

## 样式与可访问性

- 媒体继续占满现有固定比例容器，避免布局跳动。
- `<video>` 使用与图片一致的尺寸和 `object-fit` 规则。
- 多媒体序列在宽屏下采用横向网格，在窄屏下纵向排列，不使用自动轮播。
- 视频作为无声界面演示，通过 `aria-label` 提供内容说明。
- 自动循环仅用于短操作演示；减少动态效果偏好下显示静止首帧并允许用户手动播放。

## 异常处理

- 图片或视频加载失败：显示现有品牌占位，不影响其他内容。
- 浏览器不支持视频编码：通过 `<video>` 错误事件进入占位。
- 素材缺失：保留媒体配置与占位，不删除教程步骤。
