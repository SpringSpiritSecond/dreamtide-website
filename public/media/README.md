# 官网图片与视频

当前页面使用以下正式素材：

- `首页.mp4`：首屏首页操作演示。
- `不谈人间事.mp4`：浏览时切换人物原名、水墨遮盖与化名。
- `编辑-隐.jpg`：标签、隐私和注记入口界面。
- `档案.jpg`：功能区档案列表。
- `春梦了无痕.mp4`：浏览时隐藏与恢复私密片段。
- `分享.png`：教程中的梦境分享卡片。
- `档案 筛选.jpg`：回看教程中的档案筛选。
- `档案 正文.mp4`：回看教程中的档案正文。
- `词云.mp4`：回看教程中的词云操作。

下载与安装、首次刻梦仍预留 `tutorial/01-install.gif` 和
`tutorial/02-record.gif`。文件缺失时，页面显示固定比例的品牌占位，不影响布局；
补充同名素材后会自动生效。

操作演示优先使用 MP4，不需要转换为 GIF。MP4 通常体积更小、画质更好，并可在
移动浏览器中静音、循环和行内播放。图片继续使用 JPG 或 PNG。中文文件名和空格
由 Vite 的公开资源 URL 正常处理；修改文件名后必须同步更新
`src/content/siteContent.ts` 或 `src/components/Hero.tsx` 中的路径。
