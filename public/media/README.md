# 官网图片与视频

当前页面使用以下正式素材：

- `首页-web.mp4`：首页操作演示的网页兼容版本，`首页静帧.png` 是播放前封面；保留原始 `首页.mp4`。
- `不谈人间事-web.mp4`：浏览时切换人物原名、水墨遮盖与化名；`不谈人间事静帧.png` 是播放画面的兜底；保留原始 `不谈人间事.mp4`。
- `编辑-隐.jpg`：标签、隐私和注记入口界面。
- `档案.jpg`：功能区档案列表。
- `春梦了无痕-web.mp4`：浏览时隐藏与恢复私密片段；`春梦了无痕静帧.png` 是播放画面的兜底；保留原始 `春梦了无痕.mp4`。
- `分享.png`：教程中的梦境分享卡片。
- `档案 筛选.jpg`：回看教程中的档案筛选。
- `档案 正文-web.mp4`：回看教程中的档案正文；`档案正文静帧.png` 是播放画面的兜底；保留原始 `档案 正文.mp4`。
- `词云-web.mp4`：词云操作的网页兼容版本，`词云静帧.png` 是播放前封面；保留原始 `词云.mp4`。

当前页面没有引用 `tutorial/01-install.gif` 或 `tutorial/02-record.gif`。
安装页使用文字步骤，刻梦页展示现有 App 截图；如需新增教程动图，需先在
`src/content/siteContent.ts` 中配置媒体及对应文案。

操作演示优先使用 MP4，不需要转换为 GIF。MP4 通常体积更小、画质更好，并可在
移动浏览器中静音、循环和行内播放。图片继续使用 JPG 或 PNG。中文文件名和空格
由 Vite 的公开资源 URL 正常处理；修改文件名后必须同步更新
`src/content/siteContent.ts` 或 `src/components/Hero.tsx` 中的路径。
